## 30 分钟级视频实测（2026-10-07）

- **视频**：[反向旅游 陕西铜川](https://www.bilibili.com/video/BV1QuHx6mE4e)（BV1QuHx6mE4e，27 分 18 秒，旅游纪实类）
- **transcript 来源**：字幕快路径（dm/view AI 字幕，810 句 / 7111 字，零成本）
- **分块**：3 块（内容块×2 策略实为 3 块）+ 合并，共 **4 次 LLM 调用**
- **token 用量**：输入 12,184 tok + 输出 14,627 tok
- **单视频总结成本**：**¥0.0706**（≈ 7 分钱，cache-miss 空闲价）
- **总结耗时**：32.7s（首测）/ 69.4s（复测，网络波动）

### 总结质量示例（节选）

- 一句话概要：「作者以"反向旅游"探访陕西GDP垫底的铜川，按煤、瓷、仿制兵马俑、串与咸汤面的清单拍摄……讲述资源枯竭型城市的辉煌、阵痛与转型倔强。」

- 章节 4 段覆盖全片（00:00–27:04）：反向旅游开局 / 徒步下山与补给 / 铜川的瓷 / 铜川的煤与城市转型

## 全流程成本（解析 → 转写 → 总结）

| 环节 | 成本 | 备注 |
| --- | --- | --- |
| 解析（yt-dlp 元数据） | 0 | 本地 |
| 转写（字幕快路径） | 0 | dm/view AI 字幕，产品主路径 |
| 转写（本地 small ASR 兜底） | 0 | 电费忽略 |
| 转写（云端 ASR，硅基流动） | 0 | 2026-10 ASR 模型免费（docs/asr-benchmark.md） |
| **LLM 总结（27 分钟视频）** | **¥0.0706** | 唯一成本项；含 3-5 分钟短视频时按 token 比例更低 |

**结论**：单条 30 分钟视频「解析→转写→总结」全流程成本 ≈ **7 分钱**，几乎全部来自 LLM 总结输出 token（输出单价是输入的 4 倍，且合并调用输出占比高）。优化空间（如需要）：合并调用收紧 keyPoints 输出长度、或长视频摘要改用 cache hit 友好的稳定前缀。
