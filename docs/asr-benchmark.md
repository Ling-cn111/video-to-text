# ASR 中文准确率评测（CER 基准）

> 生成：阶段二准确率专项（fix/asr-accuracy）；引擎横向对比（feat/asr-engine-swap）；
> **基准审计与修复 + 云端引擎实测（feat/cloud-asr-manual，任务 D，2026-10-06）**。复现命令见文末。

## 评测方法

- **测试集**：`backend/tests/asr_benchmark/cases.json` —— 科普 / 讲解 / 教程三类 5-10 分钟 B站中文视频（实测无可用字幕）
- **音频**：下载音轨后 FFmpeg 截取**前 150 秒**转 16kHz 单声道 WAV（与参考稿对齐）
- **参考稿**：`backend/tests/asr_benchmark/refs/<videoId>.txt`，可信度分级：

  | case | 参考稿来源 | 状态 |
  | --- | --- | --- |
  | 科普 | **全文人工校对**（2026-10-06 用户对照底稿修订，含背景人声） | ✅ 绝对 CER |
  | 讲解(强BGM) | **全文人工校对**（0-45s 首轮裁决 + 0:45-150s 第二轮逐句修订；主持人有口音按实听记录） | ✅ 绝对 CER |
  | 教程 | large-v3 自动转写 | ¹ 未修订（审计确认 ref/输出比 1.00 完整，与绝对值偏差很小） |

- **CER 归一化**（两侧同规则）：zhconv 繁→简 → cn2an 数字归一 → 去标点与空白 → 拉丁小写
- **指标**：CER = 字符编辑距离 / 参考字符数；另记录转写耗时（150 秒音频）与进程内存峰值

> ⚠️ **解读前提（任务 G，2026-10-06）**：B站 AI 字幕经弹幕元数据接口 `/x/v2/dm/view` 未登录即可获取，
> **字幕快路径覆盖率高于预期——本基准 3 个用例实际都有 AI 字幕**（此前「无可用字幕」结论是 yt-dlp 未登录
> 拿不到所致）。即本表的 ASR 数字是在「有字幕但不用」的场景下测得的：**ASR 是字幕快路径的兜底而非主路径**，
> 表中数字仅用于 ASR 引擎间横向对比与兜底能力评估，不代表产品实际路径的质量上限。

## ⚠️ 基准缺陷审计与修复（2026-10-06，任务 D 触发）

**发现**：原 large-v3 参考稿在讲解（强BGM）case 上**缺失开场 0-60 秒（约 40% 内容）**，导致旧表中讲解列全部不可解读（本地 86-98% 的「全崩」与云端 88-97% 同为伪象）。证据链：

1. large-v3 本机复现（与参考稿生成同管线同音频）：**0-60s 零有效输出**（VAD 开=整段跳过；VAD 关=仅幻觉一字「带」）；
2. 参考稿正文恰好从音频第 60 秒内容开始，且 ref 字符数 461 vs 两个独立云端模型一致转出 795/821 字（语速 5.3+ vs 3.07 字/秒）；
3. difflib 覆盖率：ref 内容的 84-87% 被云端输出包含（ref 是子集）；重叠区 ref 自带错字（主床/冰穷/首名——云端反而转对为 祖传/冰穹/寿命）；
4. **用户抽听裁决（0-60s）**：确认开场确有大量语音（老罗串场、吐槽库克、KPL 梗），并修正主要错字。

**修复**：讲解参考稿重写为「用户裁决的 0-60s + large-v3 的 60-150s」（见 refs 文件头注释）。

**教训（新增 case 必查）**：参考稿=「单一模型输出」时，尺子自带该模型的时间盲区与家族偏好。新 case 必须先验 **ref 时间覆盖**（首段起点 + 语速 sanity：中文口播 3-6 字/秒）再跑 CER。

## 实测结果·绝对 CER（人工校对基准，2026-10-06 终版）

参考稿状态：**科普 / 讲解已全文人工校对**（用户对照底稿逐句修订，refs 头注明校对历程）——这两列为**绝对 CER**；
教程 ref 未修订（审计确认完整，仍为 large-v3 相对基准，标 ¹）。

| 引擎 / 模型 | 科普 CER | 讲解(强BGM) CER | 教程 CER¹ | 平均 | 耗时(150s音频) | 内存峰值 | 成本(150s) |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **Qwen3-ASR-1.7B（硅基流动云端，无时间戳）** | **6.05%** | **14.60%** | 6.43% | **9.03%** | 7-11s | ~80MB | ¥0 |
| **XingChenASR-V3.2-Ultra（硅基流动云端，带时间戳）** | 12.78% | 17.49% | **4.15%** | 11.47% | 19-43s | ~80MB | ¥0 |
| faster-whisper small (int8，本地默认) | 43.95% | 21.83% | 6.29% | 24.02% | 39-76s | ~750MB | 0 |
| faster-whisper large-v3 (int8，本地) | 31.61% | 48.49% | 0.00%* | 26.70% | 335-784s | 2.9-4.2GB | 0 |
| Qwen3-ASR-1.7B (bf16 CPU 本地) | 25.78% | 97.23%⁂ | 5.35% | 42.79% | 918-1326s | 6.6-8.1GB | 0 |

\* large-v3 为教程 ref 生成模型，自比≈0 属预期。
¹ 教程列全体仍为相对基准（ref 未修订）；平均含该列，仅供排序参考。
⁂ Qwen3 **本地**管线对强 BGM 近乎整段静默（150s 仅输出 33 字）；同模型云端托管版同音频 14.60%——本地 qwen-asr 包推理管线问题，云端可用。

**结论（任务 D ≤15% 目标终裁）**：

- **云端 Qwen3-ASR-1.7B 全 case 达标**：讲解 14.60% ≤ 15%，平均 9.03% 为全引擎最优——但无分段时间戳（时间戳定位视图退化为单行）。
- **带时间戳最优：XingChenASR-V3.2-Ultra**（平均 11.47%，讲解 17.49% 略超 15%）——质量/时间戳/速度的平衡选择，仍为默认云端模型。
- **本地 large-v3 现形**：此前作为参考稿生成器自比≈0；对人工校对基准平均 26.70%（科普喊叫 31.61%、讲解开场漏听 48.49%）——印证基准审计结论：**单模型自产参考稿会把尺子向自己偏袒**。
- **small 的真实短板是喊叫/背景人声**（科普 43.95%，此前被坏 ref 掩盖为 28.12%）；清晰口播仍可靠（教程 6.29%、讲解 21.83%）。
- 结合字幕快路径（主路径，覆盖 5/6）：**无字幕 + 强 BGM → 云端引擎；无字幕 + 清晰口播 → 本地 small；无字幕且介意隐私 → 本地 small 接受 22-44% 偏差或云端二选一**。

## 引擎横向对比解读（绝对 CER 终版）

1. **云端全面优于本地**：Qwen3 云端平均 9.03%（全 case ≤15%，任务 D 目标达成，无时间戳）、XingChen 云端 11.47%（带时间戳，默认云端模型）——均免费、7-43s、内存 ~80MB。
2. **本地 small 的真实画像**（绝对基准）：清晰口播可靠（教程 6.29%、讲解 21.83%），**喊叫/背景人声是绝对短板**（科普 43.95%）；作为默认本地引擎 + 无字幕兜底仍成立。
3. **本地 large-v3 神话破除**：对人工基准平均 26.70%（科普 31.61%、讲解 48.49%）——此前自比≈0 纯属参考稿自产自销；本地大模型在困难音频上并不优于云端。
4. **Qwen3 本地管线不可用于强 BGM**（近乎静默失败，同模型云端 14.60%）；**Fun-ASR-Nano 不可用**（幻觉，平均 90.33%，该结论与基准缺陷无关——输出与语音内容零重叠）。

## 云端 ASR 实测说明（硅基流动，任务 D）

- **模型目录（2026-10 实测，`GET /v1/models?sub_type=speech-to-text`）**：
  - `XingChenAGI/XingChenASR-V3.2-Ultra`：**支持 `response_format=verbose_json`（27 段分段时间戳）**，兼容 `language`/`prompt` 参数 → **默认云端模型**
  - `Qwen/Qwen3-ASR-1.7B`、`FunAudioLLM/SenseVoiceSmall`：仅整段 text（`verbose_json` 返回 400；引擎已自动降级 `json`，输出退化为整段单条、时间戳定位视图退化）
  - whisper-large-v3 **已不在售**（旧文档/早期调研过时）
- **计费**：ASR 模型全部**免费**（官网定价页 2026-10）；`usage` 按音频时长计（`{"type":"duration","seconds":150}`），转写 150s 音频实测 8-40s 返回。
- **引擎行为**：首选 `verbose_json`，400 自动降级 `json`；服务地址经 url_guard 校验（仅公网 http/https）；未配 `CLOUD_ASR_API_KEY` 时选择云端提交即报 `CLOUD_NOT_CONFIGURED`。

## 人声分离（Demucs）实测——旧结论作废（坏基准产物），修复基准后已复测

> ⚠️ 下表讲解列基于缺陷参考稿，「Demucs 无效」的量化结论**作废**；分离机制本身正常（格式契约通过）。修复基准后的复测见下。

| 模型 | 科普 CER | 讲解(强BGM) CER ⚠️ | 教程 CER | 平均 CER |
| --- | --- | --- | --- | --- |
| small（无分离） | 28.12% | 86.77% ⚠️ | 6.29% | 40.39% |
| small + Demucs | 29.57% | 85.25% ⚠️ | 7.10% | 40.64% |
| medium + Demucs | 71.30% | 93.49% ⚠️ | 5.35% | 56.71% |

**基准修复后复测（讲解 case，2026-10-06）**：

| 配置 | 讲解(强BGM) CER | 额外代价 |
| --- | --- | --- |
| XingChenASR-V3.2-Ultra（无分离） | 17.43% | — |
| XingChenASR-V3.2-Ultra + Demucs | **16.69%** | +144s CPU 分离（150s 音频） |

结论：修复基准后 Demucs 对云端仅 **0.7 个点**改善（17.43%→16.69%），代价 +144s——**收益边际，维持默认关闭**；强 BGM 场景的最优解是直接用云端引擎。旧结论「Demucs 对小模型幻觉无效」的方向正确（幻觉与噪声无关），但量化数字当时受坏基准污染。

启用方式：`pip install -r backend/requirements-separation.txt`；`ENABLE_VOCAL_SEPARATION=true` 或 VAD 非语音占比 > `VOCAL_SEP_TRIGGER_RATIO`（默认 0.4）智能触发；150 秒音频 CPU 分离约 91-144 秒。

## 字幕快路径 vs ASR 路径对照（任务 G，2026-10-06）

同一视频两条路径的实测对照（B站 AI 字幕经 `/x/v2/dm/view` 未登录获取，详见 backend/docs/bili-subtitle-recon.md）：

| 维度 | 字幕快路径（dm/view AI 字幕） | ASR 路径（faster-whisper small 本地） |
| --- | --- | --- |
| 响应耗时（150s 视频） | **5.2-6.7s**（含 2 次 1.5s 礼貌间隔） | 36-155s |
| 成本 | 0 | 0 |
| 质量 | B站官方 AI 转写，抽查与人工裁决稿吻合（个别错字如「唠/绕」） | 讲解类绝对 CER 21.83%（small），科普喊叫类 43.95% |
| 时间戳 | 官方生成，逐句对齐 | 模型推断 |
| 覆盖 | **6 视频中 5 个**（AI 字幕非全覆盖，央视新闻部分视频 0 轨道） | 全覆盖（任何音频） |

**结论**：有 AI 字幕的视频一律字幕快路径（产品主路径）；ASR 仅在无字幕时兜底（质量评估见上文各表）。未来评测新增 case 时应先检查 dm/view 是否有字幕轨道——有则该 case 不适合作为 ASR 评测对象（应走字幕路径，见 backend/tests/asr_benchmark/README.md 强制检查项）。

## 结论与默认配置（绝对 CER 终版）

产品路径优先级：**有 AI 字幕 → 字幕快路径**（秒级/零成本，见任务 G）；无字幕按下表：

| 场景 | 推荐配置 | 绝对 CER 依据 |
| --- | --- | --- |
| 无字幕 + 强 BGM / 快节奏解说 | **前端「转写模式」选云端**（默认 XingChenASR-V3.2-Ultra：带时间戳、免费）；追求极致准确用 `CLOUD_ASR_MODEL=Qwen/Qwen3-ASR-1.7B`（无时间戳） | 讲解 14.60-17.49% vs 本地 21.83-97.23% |
| 无字幕 + 清晰口播（默认） | `ASR_ENGINE=faster-whisper` + `WHISPER_MODEL=small`（本地，隐私友好） | 教程 6.29%、讲解 21.83% |
| 无字幕 + 喊叫/背景人声多 | 云端（Qwen3 云端科普 6.05% vs small 43.95%） | — |
| 教程/清晰口播 + 本地高准确 | `ASR_ENGINE=qwen3`（仅限清晰音频；强 BGM 会静默失败）或 whisper medium | 教程 5.35% |

运行时热词：`POST /api/transcribe` 请求体支持 `hotwords: ["Faster Whisper", "B站"]`——faster-whisper 经 initial_prompt 注入；Qwen3 经 context 注入；云端经 prompt 参数（XingChen 实测接受，输出与无 prompt 一致，效果中性）。

## 复现

```bash
cd backend
python scripts/benchmark_asr.py --models base small medium --seconds 150
python scripts/benchmark_asr.py --engine qwen3 --seconds 150
# 云端（需 backend/.env.local 配 CLOUD_ASR_API_KEY）：
CLOUD_ASR_MODEL=XingChenAGI/XingChenASR-V3.2-Ultra \
  python scripts/benchmark_asr.py --engine cloud --seconds 150 --cloud-price-per-hour 0
# 人声分离对照：
python scripts/benchmark_asr.py --engine cloud --seconds 150 --separate
# 输出：tests/asr_benchmark/results*.csv（或 --output 指定路径）
```
