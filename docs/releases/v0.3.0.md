# v0.3.0

API 设置可以存多套配置随时切换、一键测试模型可用性；桌面端多了任务侧栏；总结有了思维导图。

## API 设置：多套配置 + 测试可用性

之前的版本只能存一套「接口地址 + 模型名 + Key」：想试试别家的模型，就得把上一套改掉，而且改了地址之后 Key 还是上一家的——直到总结失败才知道配错了。

现在：

- 可以保存**多套配置**（最多 5 套），面板顶部列出每套的模型名、服务商和掩码 Key，点「使用」一键切换，当前生效的一套带「使用中」徽章
- 每套配置带自己的 Key：切到别家服务商时会自动清空上一家的 Key 并提示重填，不会再出现「新模型配旧 Key」的静默失败（确实沿用了旧 Key 也会给出强提示）
- 新增「**测试可用性**」按钮：用极短的真实请求验证「地址 + 模型 + Key」能不能用，几秒内给出结果——Key 被拒 / 模型不存在 / 余额不足 / 触发限流各有明确提示，不用等一次总结失败才知道
- 模型名输入框支持从常用模型里选（DeepSeek / 百炼 / Moonshot / 智谱 / 硅基流动 / OpenAI 的常用模型），也仍然可以自由填写
- 已保存的配置在桌面端随时从任务侧栏找到对应任务继续用

测试按钮与总结一样：Key 只随本次请求发给对应的 AI 服务商，用完即丢弃，不写入任何记录。

## 桌面端：任务侧栏

桌面窗口左侧新增「最近转写」侧栏（所有页面可见）：

- 列出最近 8 条任务（标题、平台、相对时间、进行中/已完成），点条目直接回到对应进度页或结果页
- 支持**勾选多条批量删除**
- 网页窄窗口与手机端保持原来的首页内嵌列表，不受影响

## AI 总结：思维导图

总结就绪后，结果页下方会多出一张「思维导图」：按 AI 总结的章节与要点自动生成层级树，可以折叠 / 展开每个章节。

- 详细度切换（精简 / 标准 / 详细）后导图会跟着重新生成
- 导出菜单新增「思维导图」一组：导出层级大纲 Markdown，可直接贴入 markmap、XMind 等工具继续编辑

## 其他

- 部署侧：后端新增了一个测活端点（`/api/byok/test`），**需要更新后端镜像并重新部署后，测试按钮才会生效**（桌面端 / APK 本身的其余功能不受影响）
- 任务侧栏与思维导图对「最近转写记录」的展示做了位置调整：桌面端在左侧栏，窄窗口 / 手机端仍在首页

## 已知限制

- Windows 安装包未做 Authenticode 代码签名，SmartScreen 会提示「未知发布者」，点「更多信息 → 仍要运行」
- `github.com` 在国内可能连不上，检查更新会静默跳过；下载安装包也需要能连通 GitHub
- 「测试可用性」走的是你自己填的服务商，个别服务商的接口限流策略可能影响测试结果；总结本身不受影响
