## 桌面端自动更新

这个版本给 Windows 桌面端加上了自动更新。从 v0.1.5 起，装好的客户端会在后台检查新版本，
发现更新时顶栏会出现一个「更新到 x.y.z」的按钮，点一下就能下载安装，不用再自己去
Release 页找安装包。

- 检查在启动 8 秒后自动进行一次，之后每 4 小时复查一次，全程静默——没有新版本时你不会看到任何东西
- 下载与安装由你决定：查到更新只显示提示，不会偷偷占带宽
- 安装包带数字签名，客户端会校验签名后才安装。签名不匹配的包会被拒绝
- 顶栏的「检查更新」按钮可以随时手动查，连不上服务器时会明确告诉你，并给出手动下载的出口

**关于网络**：更新服务器在 GitHub 上，国内网络可能连不上。连不上时自动检查会静默跳过
（不打扰你），手动检查则会提示失败原因并给出 Release 页链接。这是当前方案的已知限制，
后续会考虑把更新清单放到国内可达的域名上。

## 其他改动

- 桌面端版本号统一到 0.1.5（此前 `src-tauri/Cargo.toml` 曾漏改，导致安装包内嵌版本与界面不一致）
- 新增桌面端发版 workflow：以后推一个 tag 就自动构建、签名、发布，不再需要手工跑构建

## 从旧版本升级

v0.1.4 及更早的版本没有自动更新能力，需要手动下载这个版本的安装包覆盖安装一次。
之后就能收到后续的自动更新了。
