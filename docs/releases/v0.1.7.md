## 首页可以填热词了

转写前可以在「可选项 · 帮 ASR 认准专有名词」里填几个词，比如人名、产品名、专业术语。这些词会拼进语音识别的提示词，识别结果更容易写对。

不填就完全和以前一样；填了也不用记格式——逗号、顿号、分号、空格都认。上限 12 个、单个 20 字（提示词总预算要留给视频标题）。

**只影响语音识别那一环**。如果这个视频在 B站 有现成字幕，走的是字幕快路径，热词用不上——但前端照样会把它发出去，因为你不需要知道后端走了哪条路。

## APK 改由 CI 产出

以前每版都要在本地 `gradlew` 打完包再手工 `gh release upload` 到 Release。问题不在慢，在于**会忘**：v0.1.4 到 v0.1.6 都出现过 Release 上桌面端已是新版、手机端还是旧包的情况。

现在发版流水线里多了一个 `android` job，跟桌面端同一次 `v*` tag 触发、同一次 Release：

- JDK 21 + Android SDK 在 runner 上现装（Capacitor 8 / AGP 8.13 要 21，ubuntu 预装的 17 不够）
- 签名密钥从 Secrets 还原。**缺 Secret 时流水线直接失败**，而不是像 `build.gradle` 那样静默跳过 `signingConfigs.release` 产出一个装不上的废包
- 出包后用 `apksigner verify` 验签、`aapt2 dump badging` 校验 `versionName` 与 tag 一致
- 上传带 `--clobber`，重跑同一条流水线不会因为资产已存在而失败

顺带修了个真实事故：v0.1.6 发版时 `android/app/build.gradle` 的 `versionName` 漏改，APK 里还是 `0.1.5`。这份配置不跟着 `package.json` 走，现在由 CI 拦。

## 已知限制

- **Windows 安装包没有 Authenticode 代码签名**（只有 Tauri 的更新签名，客户端验签后才安装）。首次运行会触发 SmartScreen「未知发布者」，点「更多信息 → 仍要运行」即可
- 更新检查走 GitHub API / Release 页，国内网络可能连不上。连不上时自动检查静默跳过，手动检查会提示原因并给下载页
- Vercel 上的网页版国内不能直连，请用桌面端或 Android 版

## 从旧版本升级

已装 v0.1.6 的用户可点「检查更新」（桌面端在顶栏，手机端在设置面板「版本更新」）自动升级。更早的版本需要手动覆盖安装一次。

Android 用固定证书签名，可直接覆盖安装，原有设置（API Key、阅读偏好、最近转写记录、热词）都会保留。

## 校验和

本版校验和由 CI 构建产物计算，发布后按实际下载字节回填：

```
<待填>  video-to-text_0.1.7_x64-setup.exe
<待填>  video-to-text_0.1.7_x64_zh-CN.msi
<待填>  video-to-text_0.1.7_android.apk
```

核对方式：Windows 用 `certutil -hashfile <文件> SHA256`，Linux / macOS 用 `sha256sum <文件>`。
桌面端安装包另带 Tauri 更新签名，客户端会先验签再安装，签名不匹配的包会被拒绝。
