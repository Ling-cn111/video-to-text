## 手机端可以直接从 B站 接收分享了

在 B站 App 里点「分享」，选「视频转文字」，App 会直接打开并开始转写，不用再把链接复制出来粘一遍。冷启动（App 没在后台）时分享同样有效。

分享文案里通常带好几条链接（视频本体、UP 主主页、广告位），现在会挑出真正的视频页；`b23.tv` 短链由后端展开，不再因为「链接形态不认识」被误判成视频不存在。

## 手机端能检查更新了

设置面板里新增「版本更新」区块，显示当前版本、一键检查、有新版时给下载入口。

手机顶栏原本那个没有文字的钥匙图标也改好了——「API 设置」在移动端常显文字，不用再猜哪个图标是设置。

## 四个真机反馈的修正

上一版 v0.1.6 装上后暴露了四处问题，这版逐个修掉：

- **发布页停在旧版本**：`releases/latest` 会被 GitHub 302 到最近一个非 prerelease 的 tag，新包装上但 Release 未建时就被送到上一版。改为指向 `releases` 列表页
- **「取 Key」不跟随服务商**：选「阿里云百炼」时取的还是 DeepSeek 的地址（选中态从已保存配置反推，草稿没保存就回落）。改为跟随草稿；没有 Key 页面的服务商不再给死链
- **手机端看不到设置入口**：按钮文字被响应式隐藏了
- **分享报「视频不存在或链接有误」**：多链接挑错 + 短链让后端字幕与音频两条快路径双双失效，退回抓网页，而云端机房 IP 抓 B站网页恒被拒

## 桌面端

- 「检查更新」对话框里的「打开发布页」现在真的能拉起系统浏览器。之前 WebView2 会静默吞掉所有 `<a target="_blank">` 的新窗口请求，表现就是点了什么也不发生
- API 设置里的「取 Key」同样修好；`tauri-plugin-opener` 接管外部链接

## 已知限制

- **Windows 安装包没有 Authenticode 代码签名**（只有 Tauri 的更新签名，客户端会验签后才安装）。首次运行会触发 SmartScreen「未知发布者」，点「更多信息 → 仍要运行」即可
- 更新服务器在 GitHub 上，国内网络可能连不上。连不上时自动检查静默跳过，手动检查会提示原因并给下载页
- Vercel 上的网页版国内不能直连，请用桌面端或 Android 版

## 从旧版本升级

已装 v0.1.5 的用户可以点「检查更新」自动升级。更早的版本需要手动覆盖安装一次。

Android 用固定证书签名，可直接覆盖安装，原有设置（API Key、阅读偏好、最近转写记录）都会保留。
