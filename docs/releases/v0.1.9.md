# v0.1.9

桌面端导出终于能把文件存到你想要的地方了。

## 桌面端：导出弹系统「另存为」对话框

之前的桌面版点「导出」后，文件会由 WebView 静默存进系统「下载」目录——既不能选目标文件夹，也很容易找不到文件落在哪。

现在桌面端点导出（全文 TXT / Markdown、字幕 SRT / VTT 都一样）会弹出 Windows 系统「另存为」对话框：

- 可以自己选目标文件夹、改文件名，默认文件名仍是 `<标题>-文字稿` 或 `<标题>-字幕`
- 保存成功后提示「已保存到所选文件夹」
- 点「取消」不会弹任何提示；对话框或写盘出错时会自动回退到原来的下载方式，不会让你拿不到文件

网页端仍然走浏览器下载、手机端仍然拉起系统分享面板，这两端的行为没有变化。

## 其他

- Android 端本版没有功能变化，仅随桌面端同步版本号，可直接覆盖安装
- 网页端不受本次改动影响

## 已知限制

- Windows 安装包未做 Authenticode 代码签名，SmartScreen 会提示「未知发布者」，点「更多信息 → 仍要运行」
- `github.com` 在国内可能连不上，检查更新会如实报错；下载安装包也需要能连通 GitHub
