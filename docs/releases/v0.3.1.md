# v0.3.1

一次小修补：侧栏能收起了，智谱的取 Key 链接和模型名对上了，测试按钮的报错更诚实。

## 桌面端：任务侧栏可以收起

上一版加的左侧任务侧栏是固定显示的——想专心看内容时有点占地方。

现在侧栏标题栏多了一个「收起」按钮：

- 收起后内容区占满全宽，窗口左缘留一个悬浮的「任务」按钮（带未删除条数角标），点一下即可展开
- 收起状态会记住：刷新、重启之后仍是收起的，再点一下恢复

## 修复：智谱的取 Key 链接与模型名

- 修复「取 Key」链接 404：换成新版智谱控制台的密钥管理页地址
- 模型列表更新为当前世代：`glm-4.6`、`glm-4.7-flash`（免费）、`glm-4.5-air`（旧列表里的 glm-4-plus 已过时，是部分用户测试时报「模型不存在」的原因之一）

## 改进：测试按钮的报错更诚实

「测试可用性」按钮在**站点后端尚未更新**（还没有测活端点）时，之前会显示一句笼统的「请求失败（HTTP 404）」，容易让人误以为是自己的 Key 填错了。

现在这种情形会明确提示「后端镜像可能尚未更新，请先重新部署后端」。

## 改进：AI 总结明确为「自带 Key」模式

站点不再内置总结用的 Key（本来就没打算提供）。未配置自己 Key 的访客，会直接看到「填写自己的 Key」引导，而不是等一次注定失败的总结后才收到「联系部署者」的报错。已配置自己 Key 的用户完全不受影响。
