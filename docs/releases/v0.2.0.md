# v0.2.0

不用找链接了——手机里的录像、录屏课程、没有公开链接的访谈，现在直接拖进来就能转。

## 本地上传：把本地视频变成文字稿

之前的版本只能转 **B站视频链接**；视频文件本身（手机录像、录屏、导出的课程视频）没有任何入口。

现在首页粘贴链接的输入框下方多了一个「**上传本地视频**」区域：把文件拖进去，或点一下选择文件。

- 支持 **mp4 / mov / webm**，单个文件不超过 **500MB**
- 上传时有**真实进度条**（百分比），中途可以取消；快传完才发现选错文件这种事不会再发生
- 选错格式或文件太大，在本地就直接拦下并说明原因，不会白传几十 MB 才报错
- 转写完成后的体验与链接转写**完全一致**：带时间戳的文字稿、AI 总结、TXT / Markdown / SRT / VTT 导出，一样不少
- 文件在转写完成后**立即从服务器删除**，不会长期保存；转写失败时文件保留 1 天供重试——**点重试不用重新上传**
- 视频太长（内容超过约 50 分钟）会在转码阶段明确提示「视频太长」，请裁剪后再试

网页端、Windows 桌面端、Android 端三种形态都能用，行为一致。

## 其他

- 转写管线主体没有变化：链接转写的所有行为（字幕快路径、进度节奏、导出格式）与上一版完全一致
- 上传功能走「浏览器直传对象存储」，部署侧需要配置 OSS；本站已配置完成

## 已知限制

- Windows 安装包未做 Authenticode 代码签名，SmartScreen 会提示「未知发布者」，点「更多信息 → 仍要运行」
- `github.com` 在国内可能连不上，检查更新会静默跳过；下载安装包也需要能连通 GitHub
- 本地上传的内容上限约 50 分钟（音频处理上限所致），超长视频请裁剪

| --- | --- |
