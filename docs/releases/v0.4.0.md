# v0.4.0

新功能上线：重点帧——转写完成、AI 总结就绪后，可以按总结的章节和要点时间点，一键生成对应的视频画面截图。

## 结果页：重点帧

在结果页「思维导图」下方，多了一张「重点帧」卡片：

- **手动触发**：点击「生成重点帧」按钮才开始（抽帧需要从视频源下载高清画面，成本由你的显式动作承担）
- **时间点来自你的总结**：AI 总结的每个章节起点、每条要点时间，会合并去重后作为抽帧锚点（最多 12 张，相邻 2 秒内的点自动合并）
- **画面清晰度**：直接从 B站取最高 1080P 画面（HEVC 优先，下载更快），缩放到 1280 宽输出 JPEG
- **展示**：网格缩略图 + mm:ss 时间标签；图片链接限时有效，过期后刷新页面自动续期

两点说明：

- **仅支持 B站链接转写的任务**：本地文件上传任务在转写成功后源文件即被清理，暂不支持二次抽帧（界面会直接隐藏该卡片，后续版本补上）
- **生成需要 1-3 分钟**：服务端要下载视频流再逐点抽帧，生成期间显示骨架屏，完成即刷新为图片网格；失败可点「重试」

> 站点部署者注意：重点帧入口由后端能力开关驱动，**后端镜像更新部署后**该功能才对访客可见（旧后端下前端自动隐藏入口，不影响其他功能）。
