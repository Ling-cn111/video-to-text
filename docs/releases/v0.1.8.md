# v0.1.8

手机端的「检查更新」不再跳浏览器了。

## 手机端：新版本在 App 内下载并直接安装

v0.1.7 那个「下载新版本」按钮，点下去实际是打开系统浏览器、跳到 GitHub 页面、再自己找文件下载、再手动点开。手机上是三步操作，多数人点到第二步就以为「这功能没反应」。

这版把它收进 App：

1. 设置面板底部「版本更新」→ 点「检查更新」
2. 有新版时按钮变成「**下载并安装**」，点它开始下载，按钮上实时显示进度
3. 下载完自动拉起系统安装器

**仍然做不到全自动**。Android 只允许 Device Owner / 企业 MDM 静默装包，个人应用拿不到这个权限。所以最后那一下「是否安装」必须你自己点，而且**首次使用时需要在系统设置里允许本应用「安装未知应用」**——App 会把你送到那个设置页，回来再点一次即可。

同样地，任何一步失败（网络断了、Release 里没有 APK 资产、原生插件不可用）都会退回浏览器下载，不会让你卡在一个必然失败的按钮上。

## 其他

- 桌面端与网页端没有功能变化，仅版本号同步
- 网页端不受本次改动影响（应用内安装只在 Android 壳里生效，网页构建里连入口都不渲染）

## 已知限制

- Windows 安装包未做 Authenticode 代码签名，SmartScreen 会提示「未知发布者」，点「更多信息 → 仍要运行」
- `github.com` 在国内可能连不上，检查更新会在连不上时如实报错而不是静默跳过；下载 APK 也需要能连通 GitHub
- 手机端首次使用应用内安装需要授权「安装未知应用」，这是 Android 平台的设计，应用无法绕过

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows | `video-to-text_0.1.8_x64-setup.exe`（NSIS，推荐）/ `video-to-text_0.1.8_x64_zh-CN.msi`（WiX） |
| Android | `video-to-text_0.1.8_android.apk`（Android 7.0+，覆盖安装即可升级） |

已装旧版的用户可直接在应用内升级：桌面端点顶栏「检查更新」，手机端在设置面板「版本更新」。
